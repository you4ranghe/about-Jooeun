3군은 /projects/yutnori 한 장을 세 방향으로 그린 것입니다. 글은 예시가 아니라 저장소 README 에서 확인한 실제 내용이라, 고르시면 그대로 원고가 됩니다. 세 시안 모두 “눌러야 불러오는” 실행 미리보기를 달았고 누르기 전에는 통신하지 않습니다. 기존 상세페이지가 작고 얇았던 문제는 세 방향 모두에서 본문 크기와 굵기를 올려 해결했습니다.

1·2군 다섯 시안은 모바일 폭까지 대응하고, 키보드로 조작할 수 있으며, prefers-reduced-motion을 지킵니다. D·E는 이미지 파일을 하나도 쓰지 않고 CSS와 SVG로만 그렸습니다. E에는 “목록으로 보기” 버튼이 있어, 숨은 물건을 찾을 생각이 없는 방문자도 바로 전체를 훑을 수 있습니다. 웹폰트는 Google Fonts 링크라 인터넷 연결이 필요합니다.
